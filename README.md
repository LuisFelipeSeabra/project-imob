# Project Imob

Startup de realidade virtual para imobiliárias.

## Objetivo

Permitir que clientes de imobiliárias visualizem terrenos, casas e decorações em realidade virtual a partir de fotos do ambiente.

## Tecnologias Iniciais

- Captura: smartphone
- Fotogrametria: Meshroom / COLMAP
- Otimização 3D: Blender
- Visualização: A-Frame + Three.js (WebXR)
- Backend: Supabase
- Hospedagem: Vercel

## Branches

- `master`: branch principal de produção
- `branch-init`: branch de inicialização e experimentação
